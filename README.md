# 🇬🇧 English Adventure

Spletna aplikacija za učenje angleščine, namenjena učencem **2. in 3. razreda osnovne šole**.

Otroci skozi kratke mini-igre spoznavajo osnovne angleške besede in preproste povedi. Teme so razporejene kot pustolovščina: Animals → Colours → Food → Family → School → Numbers. Ko otrok dovolj dobro reši eno temo, se odklene naslednja. Za uspešno rešene naloge zbira zvezdice ⭐ in značke 🏅.

## 🎮 Mini-igre

| Mini-igra | Opis | Tema |
|---|---|---|
| 🖼️ What is this? | Prikaže se slika, otrok izbere pravo besedo. | vse teme |
| 🔊 Listen and choose | Aplikacija izgovori besedo, otrok klikne pravo sliko. | vse teme |
| 🔤 Complete the word | Otrok dopolni manjkajočo črko (`C _ T`). | Animals, Food |
| 🔗 Match the pairs | Otrok poveže besede s slikami. | vse teme |
| 🎨 Colour challenge | Otrok izbere predmet prave barve (*Choose the red apple*). | Colours |
| 👨‍👩‍👧 My family | Otrok poveže družinske člane z besedami. | Family |
| 🔢 Count! | Otrok prešteje predmete in izbere pravo število. | Numbers |
| 🧩 Build a sentence | Otrok iz besed sestavi poved (*This is a dog.*). | vse teme |
| 🎒 Pack your school bag | Otrok prenese prave predmete v šolsko torbo. | School |
